@log-ingestor/mssql

Disk-first structured logger for Node.js with automatic ingestion into Microsoft SQL Server (MSSQL).

No ELK. No Kafka. No manual log management.

Links

📦 npm package: https://www.npmjs.com/package/@log-ingestor/mssql

📂 GitHub repository: https://github.com/aritvyas/log-ingestor-mssql

How it works

  • Node.js app writes structured logs to disk
  • Background Go ingestor starts automatically
  • Logs are batched and inserted into MSSQL
  • Application never blocks on DB writes
