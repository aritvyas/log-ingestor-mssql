@log-ingestor/mssql

Disk-first structured logger for Node.js with automatic ingestion into Microsoft SQL Server (MSSQL).
No ELK
No Kafka
Crash-safe
Production-ready

Logs are written to disk first and ingested in the background by a native Go binary. Your application never blocks on database writes.

npm GitHub

How it works

  • Node.js app writes structured logs to disk
  • Background Go ingestor starts automatically
  • Logs are batched and inserted into MSSQL
  • Application never blocks on DB writes

Usage

const { createLogger } = require("@log-ingestor/mssql");

const logger = createLogger({
  service: {
    name: "order-service",
    version: "1.0.0"
  },
  logging: {
    logDir: "./logs"
  },
  db: {
    type: "mssql",
    connection:
      "Server=localhost,1433;" +
      "Database=logsdb;" +
      "User Id=sa;" +
      "Password=***;" +
      "Encrypt=true;" +
      "TrustServerCertificate=true;"
  }
});

logger.info("order created", { orderId: 123 });
logger.error("payment failed");

What this is NOT

  • Not a console logger
  • Not an ELK stack
  • Not a metrics system
